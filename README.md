# Jammu Expedition

A cinematic, single-page travel website designed to showcase the beauty, culture, and adventure of Jammu. The project presents a modern tourism experience with immersive visuals, storytelling-led sections, and an interactive trip-planning interface.

## Overview

Jammu Expedition is a visually rich landing page for exploring Jammu's spiritual heritage, mountain landscapes, and curated travel experiences. The site blends a premium editorial aesthetic with practical travel planning, giving visitors a sense of the region's atmosphere before they even arrive.

## Highlights

- Immersive hero section with animated mountain-style background and layered visual effects
- Curated travel routes for different moods and trip styles
- Custom itinerary planner for selecting trip duration and travel profile
- Elegant motion and reveal effects for a polished magazine-style UX
- Responsive design for desktop and mobile browsing
- Clean static HTML/CSS/JS implementation without a heavy framework

## Featured Experiences

The website highlights several travel themes, including:

- Spiritual journeys and sacred destinations
- Pine-covered hill escapes and scenic mountain routes
- Heritage-rich city exploration
- Highland and glacial expedition experiences

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS CDN
- Google Fonts
- SVG and CSS-based graphics for visual effects

## How to Run

Since this is a static website, you can view it locally by opening `index.html` in a browser.

Alternatively, you can run a local static server from the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Purpose

This project is intended to act as a brochure-style tourism website that promotes Jammu as a destination for nature, culture, adventure, and spiritual travel. It is suitable for marketing, travel inspiration, and landing-page presentation.
